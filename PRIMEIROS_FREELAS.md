# Preparação para os primeiros freelas

Atualizado em 09/11/2026. Os projetos abaixo são demonstrações de estudo e portfólio, sem clientes ou resultados comerciais atribuídos a eles.

## Trabalhos para cadastrar no 99Freelas

### Site institucional responsivo — Drew Studio

Projeto demonstrativo de site para um estúdio criativo fictício, desenvolvido com HTML, CSS e JavaScript. Inclui layout para celular e computador, tema claro/escuro, navegação por seções e formulário que gera um briefing para download no próprio navegador. Testado em duas larguras de tela.

Imagem: https://github.com/SamirGedeon/Lading-Page/blob/main/docs/portfolio/drew-capa.png

### Controle de estoque com painel e banco de dados

Projeto demonstrativo em Java e Spring Boot com painel web, cadastro, consulta, edição e exclusão de produtos. Inclui busca por nome, indicadores de quantidade e valor, validações e banco H2 em arquivo. Testes automatizados verificam a API, o painel e os dados após reiniciar a aplicação. Demonstração local, sem autenticação.

Imagem: https://github.com/SamirGedeon/estoque-spring-api/blob/main/docs/portfolio/estoque-capa.png

### Vitrine interativa de produtos — Fruta

Vitrine demonstrativa com HTML, CSS e JavaScript para uma marca fictícia de refrigerantes. Possui três sabores, navegação circular por setas e teclado, seleção direta por indicadores e layout adaptado ao celular. Testada em desktop e celular. Não inclui loja, carrinho ou pagamento.

Imagem: https://github.com/SamirGedeon/Site-Refri/blob/main/docs/portfolio/vitrine-capa.png

- Drew: seleção de serviço, download e conteúdo do briefing, tema persistido, imagens e larguras de 1440 e 390 pixels.
- Fruta: avanço, retorno, navegação circular, teclado, indicadores, imagens e larguras de 1440 e 390 pixels.
- Estoque: testes Java, cadastro/edição/filtro/exclusão no painel e persistência após reiniciar o processo Java.
- Evidências: aba Actions de cada repositório. As capas são capturas reais geradas durante os testes.

### Texto para adaptar e enviar após revisar o escopo

Olá! Li seu projeto e a ideia é organizar os trabalhos de design e os vídeos em um portfólio fácil de explorar, principalmente no celular.

Posso desenvolver a apresentação inicial, a galeria de projetos organizada por categorias e a seção audiovisual com miniaturas e reprodução do vídeo selecionado na própria página.

Trabalho com HTML, CSS e JavaScript e tenho um site demonstrativo de estúdio criativo para apresentar minha abordagem de layout e navegação. Posso mostrar as imagens desse projeto pela plataforma.

Minha sugestão inicial é entregar uma página principal com as seções do portfólio, até 12 projetos de design e 8 vídeos, usando os materiais fornecidos, com duas rodadas de ajustes. Entrego os arquivos e orientação para publicação na hospedagem compatível.

Antes de confirmar o valor e o prazo, preciso saber: os vídeos já estão no YouTube/Vimeo ou são arquivos que precisarão ser hospedados? Você também precisa editar o conteúdo sozinho por um painel?

Com essas informações, alinhamos a solução e a entrega sem surpresas.

### Estimativa interna para revisão

Ponto de partida sugerido: R$ 650 pelo trabalho, prazo de 7 dias corridos após os materiais e a garantia do pagamento. É uma estimativa própria, não uma pesquisa de preço de mercado nem uma oferta já enviada. Conferir o valor final exibido pelo 99Freelas antes de enviar.

Essa estimativa considera página estática, materiais prontos e vídeos incorporados de serviço existente. Um painel administrativo, upload/processamento de vídeos ou novas páginas muda o orçamento.
